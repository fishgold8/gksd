# AnimAuto — автоматизация анимации в Maya

Аддон для Maya 2027 (работает и с 2022–2026) под риг Бати (AdvancedSkeleton
+ лицо на текстурах).

## Установка

1. Скопируйте папку проекта куда угодно, например `D:/tools/AnimAuto`.
2. Перетащите `install.py` во вьюпорт Maya.
3. На текущей полке появится кнопка **Anim**, и сразу откроется окно.

Запуск вручную из Script Editor (Python):

```python
import animauto.ui
animauto.ui.show()
```

## Что умеет

### Лицо
- Превью всех глаз (`tex/eyes/eye_XX.png`) и ртов (`tex/mouth/mouth_XX.png`).
  Клик ставит `Face_ctrl.eyes` / `Face_ctrl.Mouth` и ключ со ступенчатой
  интерполяцией, чтобы текстура переключалась без промежуточных кадров.
- Слайдер `Expressions` (blendShape головы, 0–21).
- Пресеты эмоций: сохраните сочетание глаза + рот + Expressions под именем
  («злой», «удивлён»…) и ставьте его одним кликом. Пресеты хранятся в
  `prefs/animauto_face_presets.json`.
- Если текстуры не найдены (пути `D:/...` с другого компьютера), укажите
  папку кнопкой **Папка…**.

### Моргание
Выберите номер закрытых глаз и интервал. Моргания расставятся по
playback range. После моргания глаза возвращаются к тому, что было в этот
момент. Уже существующие ключи глаз (смена эмоций) не затираются.

### Липсинк
Возьмите WAV из сцены или выберите файл и задайте для каждого уровня
громкости форму рта (тишина / тихо / средне / громко). Аддон ставит
ключи `Mouth` по громкости. Дополнительно можно открывать челюсть `FKJaw_M`.

### Тело
- Выделить все контролы, поставить ключ, сбросить позу (всё или выделенное).
- Зеркалить выделенные контролы на другую сторону и отразить позу L↔R.
- FK↔IK для рук и ног с подгонкой: конечность не прыгает при переключении,
  ключи ставятся на кадре переключения и на кадре перед ним.

Все действия отменяются одним Ctrl+Z.

## Настройка

Имена узлов рига, правила зеркала и значения по умолчанию лежат в
`scripts/animauto/config.py`. Если превью глаз/рта не совпадают с тем, что
видно во вьюпорте, поменяйте `EYES_INDEX_OFFSET` / `MOUTH_INDEX_OFFSET`.

## Тесты

Логику без Maya (моргания, анализ звука, зеркало, pole vector) можно проверить так:

```
python -m unittest discover -s tests
```
