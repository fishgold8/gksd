# Медиатека для новостных роликов

Собирает фото и видео из Telegram-канала Кремля на английском
(`@news_kremlin_eng`), режет видео на отдельные планы, подписывает каждый
план (кто в кадре, сцена, крупность, одежда, место, событие) и раскладывает
по папкам. Агент ищет материал одной командой `find.py`, не читая весь индекс.

## Что получится

```
data/
  library/                          ← готовые файлы, это и копировать на Google Диск
    putin/
      speech/   2026-10-15_putin_speech_close_new502-1-s02.mp4
      talk/     2026-10-14_putin_erdogan_talk_medium_new501-1.jpg
      military/ ...
      solo/ meeting/ handshake/ walk/ press/ ...
  index.jsonl                       ← одна строка на файл (для find.py)
  people_summary.json               ← кто есть и сколько материалов
  index.db                          ← рабочая база конвейера
  raw/, keyframes/                  ← исходники и кадры-превью (можно не переносить)
```

Имя файла читается без открытия: `дата_главный-человек_собеседник_сцена_крупность_id`.

## Установка (один раз)

Нужны Python 3.10+ и ffmpeg.

```
pip install -r requirements.txt
```

Для распознавания лиц положите 5–10 чётких фото лица в `people/putin/`,
`people/trump/` и т. д. Без них всё равно работает, но ИИ будет смотреть
больше кадров и обойдётся дороже.

Для ИИ-подписей нужен ключ Anthropic: `export ANTHROPIC_API_KEY=...`.

## Запуск

```
python run.py all                 # всё по порядку; повторный запуск докачивает только новое
python run.py tag --no-vision     # подписать только по тексту постов, бесплатно
python run.py stats
```

Отдельные шаги: `scrape`, `big`, `shots`, `faces`, `tag`, `export`.

Настройки лежат в `config.json`:
- `max_posts` — ограничить число постов, для пробы ставьте 50;
- `since_date` — не брать посты старше этой даты;
- `vision_model` — модель для подписей; `claude-haiku-5-5` примерно в 40 раз дешевле, но точность ниже;
- `min_shot_sec` — короче этого планы выбрасываются;
- `max_videos_per_event` / `max_photos_per_event` — сколько видео (2) и фото (3) брать с одного
  события; берутся разные планы (крупность, сцена, действие). Посты одного дня с одним и тем же
  событием (длинное выступление, выложенное кусками) считаются одним событием.

### Большие видео

Веб-версия Telegram отдаёт без входа только видео примерно до 20 МБ. Большие
видео записываются в базу как `video_big`, их докачивает шаг `big` через
Telegram API:

```
export TG_API_ID=...  TG_API_HASH=...   # my.telegram.org → API development tools
python run.py big                       # при первом запуске спросит номер и код из Telegram
```

## Как экономятся кредиты

1. **Подписи из текста поста (бесплатно).** Кто, где и какое событие — Кремль пишет это сам.
2. **Нарезка на планы и распознавание лиц (локально, бесплатно).** Сразу дают людей в кадре и крупность.
3. **ИИ видит только планы с нужным человеком.** Кадры уменьшены до 512 px, все кадры одного поста уходят одним запросом, ответ — короткий строгий JSON.
4. **Агент не читает индекс целиком.** Он вызывает `find.py`, который возвращает 5–10 коротких строк (см. `AGENT.md`).

## Добавить нового человека

1. Добавьте запись в `people.json` (id и варианты написания имени).
2. Положите фото лица в `people/<id>/`.
3. Добавьте id в `focus_people` в `config.json`.
4. Запустите `python run.py all`.

Другие каналы добавляются в `channels`.
